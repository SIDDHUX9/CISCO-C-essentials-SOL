# Cisco C++ Essentials – My Lab Solutions

Welcome to my repository of **self-written solutions** for the [Cisco C++ Essentials Course](https://skillsforall.com/).

## 📘 About the Course
Cisco's C++ Essentials course covers fundamental programming concepts using the C++ language. It includes hands-on lab exercises to help learners develop core programming logic, syntax knowledge, and problem-solving skills.

## 💻 About This Repository
This repo contains **my own solutions** to the lab problems in the course. I did **not use the "View Solution" feature** provided in the course — all code is written based on my own understanding and logic.

Each solution includes:
- Clean, readable C++ code
- Inline comments explaining my approach
- Occasional notes on mistakes I made and what I learned

## 🧠 Why I Made This Repo
- To track and reflect on my progress while learning C++
- To practice writing clean, maintainable code
- To demonstrate my commitment to learning and improving as a programmer
